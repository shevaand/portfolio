# My Portfolio

My personal portfolio website, built with Next.js and TypeScript, to showcase my projects, skills, and experience.

## Features

- Project portfolio with descriptions and technology lists
- Project details and screenshots
- Internationalization with English and German translations
- Responsive user interface
- Contact form with input validation using Zod and email sending with Resend

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- next-intl
- Zod
- Resend
